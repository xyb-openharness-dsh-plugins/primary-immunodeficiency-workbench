# SCENARIOS · 一期场景清单

- 版本：v0.1.0-skeleton · 2026-11-12
- 声明：0 患者访谈。以下场景为开发者按病种知识的假设排序，M1 检索一手叙述（病友社区公开帖、
  指南患者教育材料）校准；检索不到就保持 0 访谈声明，不伪造引语。

## S1 感染频次盘点（最高频）

- 谁：家长代记 / 成人患者
- 触发：又要去复诊，医生问「这一年感染了几次」，答不上来
- 路径：看板 → 感染事件 → 按年份/部位汇总 → 导出或复制给医生
- 可观察产物：近 12 月感染次数与列表、距上次感染天数
- 红线：频次是「数出来的事实」，不写「免疫水平差/恶化」

## S2 替代治疗节律管理

- 谁：维持期患者/家长
- 触发：每 3–4 周一次 IVIG，忘了上次什么时候输的、这次该约什么时候
- 路径：替代治疗页 → 按次记录 → 页顶显示「按你自己的历史，间隔通常 N–M 天，上次是 X 日期」
- 红线：只推算个人历史，不写「应于」「建议」；不良反应只记事实

## S3 化验单放一起看

- 谁：患者/家长
- 触发：IgG 谷浓度每次都在不同医院测，单子攒一沓不知道怎么比
- 路径：化验页 → 可比组卡片 → 一图秀（组内）→ 点点看原始记录
- 红线：跨方法/机构不合并不连线；「不同方法不合并」与数字同屏

## S4 接种问题准备

- 谁：家长
- 触发：幼儿园要打疫苗，怕踩活疫苗禁忌，想知道该怎么问
- 路径：接种口径页 → 看医生已确认的原话 → 没有原话则复诊问题清单自动加一条「接种禁忌与安排」
- 红线：本台不回答能不能打；只帮把问题带给医生

## S5 复诊材料准备

- 谁：家长/患者
- 触发：复诊前要把这几个月的感染、替代治疗、化验整理成一页
- 路径：复诊问题清单 → 汇总预览（私密过滤提示）→ 导出
- 产物：带版本号导出文件 + 问题清单条目
