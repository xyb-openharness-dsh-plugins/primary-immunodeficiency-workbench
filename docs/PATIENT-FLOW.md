# PATIENT-FLOW · 患者旅程与页面映射

- 版本：v0.1.0-skeleton · 2026-11-12
- 声明：0 访谈；旅程为开发者假设，M1 校准后逐页复核（孤儿页=0 断言进 check）。

## 旅程阶段

1. **诊断评估期**：反复感染 → 免疫功能检查 → 基因确诊 → 建立诊断依据档案
2. **置换启动期**：IVIG/SCIG 方案确定 → 建立按次记录习惯 → 学习看化验单
3. **维持期**（主体）：按周期置换 → 感染监测 → 年度免疫评估 → 疫苗/入学/生活决策咨询
4. **波折期**：突破性感染/并发症 → 调药或加量 → 与医生重新对齐方案
