## 关键交互决定

1. 感染/置换/化验表单 ≤6 字段，三态按钮（保存并继续录入 / 保存并关闭 / 取消）；
2. 无裸删除：更正=新增版本；「查看历史」入口；
3. 数字输入 inputmode=numeric；日期未知→显式「未知」不空串；
4. AI 通道：每页「和 AI 讨论」只填草稿不发送（agent-draft 契约）；候选逐项核对入档，拒收零副作用；
5. 整页视图：>1.5 屏内容走整页面板（A1–A10），Esc 一层一退；
6. 折叠卡用原生 details（32F）；指标卡真 3D 翻转定高 194px（1.4 三断言）。
