# DEV-REQUIREMENTS · 小御宝 ImmuPal

- 版本：v0.1.0-skeleton · 2026-11-12
- 口径：本文档写「必须怎样 + 适用语境 + 反例 + 验收」，不写愿望。

## 一、患者视角红线

1. 功能按患者关心的信息维度组织（这次病了几次 / 下次大概什么时候输 / 化验单怎么看 / 该问医生什么）；
   医生任务冒充患者需求属独立评审一票否决。
2. 每条功能线挂患者原话；本台 0 患者访谈，以下场景为开发者假设（M1 检索一手叙述补位，补不到就保持「0 访谈」声明，改写句不冒充引语）。
3. 0 临床审核：全部阈值、参考范围、频次口径一律【待核】占位，以患者自己的医生安排为准。

## 二、硬边界

- 本台只做「本机资料整理与回顾」：不做诊断、不给处置建议、不做病情判定、不生成任何接种建议。
- 界面不替医生说话：紧急口径只呈现医生已确认原话；无原话时空态引导「把这个问题带给你的免疫科医生」。
- 活疫苗等接种禁忌只可呈现指南级科普事实（标来源与版本），不写「你可以/不可以接种」。

## 三、数据口径

- 「仅回顾，不解读」「不同方法/机构不合并」「解读归医生」三句与数字同屏。
- 化验（IgG/IgA/IgM、淋巴细胞亚群）按方法/单位/机构可比组展示，跨组不合并不做差不连线。
- 派生值（距上次感染天数、近 12 月感染次数、下次置换参考间隔）读时计算，不落库、不判定。
- 私密三出口（看板/导出/AI 上下文）同一过滤函数；页内可见「N 条中私密 M 条」。

## 四、功能线（患者视角，M1 后逐条挂证据）

| 线 | 患者关心 | 落点 |
| --- | --- | --- |
| 感染事件 | 一年病了几次、间隔多久、每次用了什么药 | 感染折叠卡 + 事件泳道 + 派生频次 |
| IVIG 置换 | 每次剂量/机构/反应，下次大概什么时候 | 置换按次记录 + 个人历史参考间隔 |
| 化验档案 | 化验单指标怎么看、和上次比 | 可比组指标卡 + 一图秀 |
| 预防用药 | 现在在用什么预防药 | 用药登记（照抄医生原话） |
| 接种口径 | 能不能打疫苗 | 医生确认原话展示，无则引导问医生 |
| 复诊准备 | 见医生前把问题理清楚 | 复诊问题清单 |

## 五、可回退默认值（无人值守，待晨审追认）

1. 服务主体：PID 患者本人及家长代记（R3 双视角：本人/代记标签贯穿）。回退：成人患者单视角。
2. 病程覆盖：确诊评估期 + 置换维持期全病程；不做产前/新生儿筛查期。回退：仅维持期。
3. MinerU：不接入（六部件装齐但如实标注「勾选与保存不联网」，解析通道降级为手工录入）。
4. 品牌占位名：小御宝 ImmuPal（"御"取免疫防御之义；晨审可改）。
5. 试验线：裁剪（DEV-PLAN §四，实测 601 条 2026-11-12）。回退：按 35 号补齐四段链路。

## 六、验收红线（签认必查）

- 禁词 0（诊断/复发判定/用药建议/治愈率/匹配指数类）；非肿瘤语义（无分期/线序/疗效/D+N）。
- check 链全绿、test 全过、audit 数字照抄；SKIP 不计覆盖；探针带显式 --url。
- 版本号、CHANGELOG、README 版本、截图版本四处同源。
