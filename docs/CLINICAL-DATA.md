## 专属数据维度（PID 特有，M3 schema 输入）

- 感染事件：日期（可未知）、部位、病原（若已检）、抗感染用药、医生原文处置、私密标记、代记归属
- IVIG/SCIG 置换：日期、制剂、剂量 g/kg、机构、输注反应、私密标记、代记归属
- 免疫化验：项目（IgG/IgA/IgM/IgE/淋巴细胞亚群等）、值、单位、方法、机构、参考范围文本（不判定）、可比组键
- 预防用药：药名、医生原话剂量口径、起始、状态（在用/已停按医生原话）
- 接种口径：医生确认原话、日期、医生/机构（只展示不生成）
- 诊断依据：基因检测/免疫功能报告登记（原件引用，不解析内容为判定）
