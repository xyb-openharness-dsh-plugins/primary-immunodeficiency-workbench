# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：原发性免疫缺陷病（PID）患者及家属照护者；含患儿家长代记（本人/代记双视角）、IVIG 维持治疗中的成人与儿童患者、诊断随访期患者；患者组织志愿者协作使用

场景：感染事件记录（部位、病原若已检、抗感染用药、医生原文处置，派生距上次感染天数与近 12 月感染次数，读时计算不落库）；IVIG 替代治疗按次记录（日期、剂量 g/kg、机构、不良反应，仅按个人历史推算参考间隔不写应输日期）；免疫球蛋白 IgG/IgA/IgM 与淋巴细胞亚群化验档案（标注方法/单位/机构可比组，跨方法不合并）；预防性抗感染用药登记（照抄医生原话）；预防接种口径（医生已确认原话，无原话时空态引导问医生）；复诊问题清单

核心流程：
1. 选择本机资料目录并导入免疫检验/出院小结/接种记录报告
2. 核对候选信息，建立诊断依据与免疫评估档案
3. 记录感染事件、IVIG 替代治疗与预防性用药
4. 查看免疫球蛋白趋势与替代治疗间隔参考（可比组口径）
5. 生成复诊准备与接种咨询材料

完成结果：得到来源可追溯、可核对的个人病程档案：感染事件时间线与频次概览、IVIG 替代治疗记录与下次参考间隔、免疫球蛋白水平趋势（可比组内）、预防性用药与接种口径留痕、复诊准备材料；所有候选信息经用户核对入档；解读归医生

初始布局选择：business-first
