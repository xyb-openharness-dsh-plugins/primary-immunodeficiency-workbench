## 一级重名率实测（M1 结构对比子代理，2026-11-13）

- 对照基准：breast-cancer-workbench/prototypes/v0.4 一级 8 项（看板/病情整理/病情一图秀/临床/营养支持/心理支持/全程与康复/收藏与回顾）× PID 计划功能线 7 条。
- **直接同名/近义可复用 = 2/7 ≈ 29% ≤ 70%，达标**（化验→指标检测近义、复诊清单→收藏与回顾近义；感染/替代治疗/预防用药/接种口径/家长代记全部无对应，需新建）。
- 可整体照搬的病种无关导航：看板/病情整理/一图秀/临床/心理支持 5 项结构。
- 移植样板改定：cervical-workbench 未过 V1（docs/TASKS.md T01–T06 全「待开始」、CHANGELOG 尾行「真机走查待人工」），**改用 cidp-workbench 0.2.0（check 0 · test 42/42 · audit 44/44 · probe 44/44 · 已装 Desktop）为移植样板**；breast v0.4 仍为成熟对比基准、aml v0.2 为结构基准。

## 语义替换清单（肿瘤残留 → PID 表达）

| 肿瘤表达（出处） | PID 表达 |
| --- | --- |
| `D+N 状态卡`（breast app.js ~L625）、`Day+N 时间轴`（aml） | 锚点=「确诊日/末次 IVIG 日」→「距上次替代治疗 N 天」；D+N 仅保留给 HSCT 档案 |
| 我的分期/FIGO/分期档案（cervical） | 基因诊断与分型（IUIS 分类），「只记医生给的诊断，不自算」 |
| 按病期与线序（cervical README） | 替代方案调整轮次 |
| 疗效/缓解/复发恐惧 FCR（aml mind-feel） | 感染控制情况、年感染次数变化；「反复感染的担心」 |
| 肿瘤标志物（cervical labs） | IgG/IgA/IgM 谷浓度 + 淋巴细胞亚群 |
| 病理与分子/病理（cervical、breast clinical） | 基因检测报告 + 免疫表型；「病理」删 |
| 化疗第 N 周期前检验（breast） | 第 N 次替代治疗前/后检验 |
| 术后恢复/臂围差 alert-strip（breast care 组） | 整组删除，看板首卡换「感染预警条」 |
| 生育保留（cervical fertility） | 预防接种与家庭照护 |
| IVIG「置换」（肿瘤/移植语境） | 「替代治疗」（replacement therapy；「置换」=血浆置换，术语错位） |

## 差异化条目（M0 版保留）

| # | 场景 | 功能 | 怎么验 |
| --- | --- | --- | --- |
| 1 | 孩子一年反复肺炎/中耳炎，就诊前想给医生看「这一年感染几次、间隔多久、每次用了什么药」 | 感染事件折叠卡（日期/部位/病原若已检/抗感染用药/医生原文处置）+ 事件泳道；派生「距上次感染 N 天 / 近 12 月感染次数」读时算 | A/B 两套合成档案切换后时间线、卡片、导出同步且不串档（无头断言出数字） |
| 2 | IVIG 每 3–4 周输一次，日期/剂量/反应散在不同医院 | 替代治疗按次记录（日期/剂量 g/kg/机构/不良反应）+ 按个人历史推算参考间隔（明示「按你自己的历史推算」），不写「应于某日」 | 替代治疗列表与泳道渲染断言；参考间隔文案含「按你自己的历史」 |
| 3 | IgG 谷浓度在体检与专科各测一次，单位/方法不同 | 免疫球蛋白按方法/单位/机构可比组展示；跨方法不合并、不做差、不连线；参考范围【待核】 | MT06 类断言：跨方法合成数据下曲线断线；页面可见「不同方法不合并」 |
| 4 | 家长想知道孩子能不能打疫苗 | 只展示医生已确认的接种口径原话（带日期）；无原话空态引导问医生；不生成建议 | 禁词扫描 0 命中；空态文案断言 |
| 5 | 家长代记 vs 患者本人看同一档案 | R3 双视角：本人/代记标签贯穿记录与导出 | 两视角切换后记录归属标签断言 |
| 6 | 确诊依据材料（基因检测、免疫功能报告）想集中存放与回看 | 诊断依据档案（原件登记 + 候选核对入档） | 档案页与导入链路探针 |

## 家族差异化对照（防撞车）

| 仓 | 重叠 | 本台不同 |
| --- | --- | --- |
| cidp-workbench（小髓宝） | 都有 IVIG 输注线 | CIDP=神经复发—缓解+电生理；本台=感染事件+免疫球蛋白谷浓度+接种口径，无复发判定语义 |
| cold-agglutinin（小暖宝） | 都是罕见病慢病 | CAD=溶血指标+输血特殊要求；本台=替代治疗维持+感染监测，无冷激发语义 |
| anca-vasculitis / pbc / aosd | 都是免疫方向 | 它们=自身免疫炎症活动度；本台=免疫缺陷（防御不足），核心是感染频次与替代治疗节律 |
| behcet | T1 免疫 | 口-生殖器溃疡+针刺反应线，与本台无共享功能语义 |
